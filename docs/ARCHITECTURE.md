# 实现说明

## 一条渲染管线

```text
DSH 当前项目 + 当前对话
  └─ index.js：注册 /asset-color-match 和 asset_color_match
      └─ server.js：每个对话一个本地会话，监听 127.0.0.1 随机端口
          ⇄ web/bridge.js：鉴权、按需接指令、传回结果
              └─ web/index.html：原有 Grade / Keyer / CC 和 Canvas 渲染器
```

系统默认浏览器由 Windows URL 处理器打开，链接带随机控制令牌；页面读取后从地址栏移除令牌，存入该标签的 sessionStorage。后续请求用 Bearer 令牌和浏览器会话 ID。一个 DSH 对话只接受一个活跃浏览器工作台，避免不同标签争抢指令。

网页通过长轮询等待命令。没有公网监听、外部脚本、模型调用或 WebSocket 服务。未启用 DSH 桥接时，同一 HTML 仍能离线使用。

## 工具动作

| action | 输入 | 返回/作用 |
|---|---|---|
| `open` | 无 | 打开默认浏览器，返回工作台地址和输出目录 |
| `load` | `reference`、`files`，项目内相对或绝对路径 | 载入参考/资产，返回列表和原图缓存路径 |
| `inspect` | 无 | 此刻图片列表、当前参数、原图路径、历史输出 |
| `set` | `updates`，每项为 `id` 或唯一 `name` + 部分参数 | 原子校验本次所有更新后填入网页 |
| `export` | 可选 `ids`、`suffix`、`outputDir` | 读取当前参数，原尺寸渲染；返回实际保存路径与 `parametersUsed` |
| `close` | 无 | 关闭本地控制接口，缓存与成品保留 |

`inspect` 不代表已经看过图。工具描述要求智能体用 DSH 原生读图工具查看返回的路径后，再建议针对图片的数值。插件本身既不推理画面，也不另外申请模型 Key。

`set` 支持 Grade、quick、Keyer、CC 和 gradeMask 的部分更新，未提供字段保留当前值。优先使用资产 ID；重名时禁止按名字猜选。数组均为 RGB 三值，Keyer range 为四值。最终数值边界沿用网页 `normalizePreset`，一项错误时整批不修改。

示例（仅说明接口，数值不代表针对实际素材的建议）：

```json
{"action":"set","updates":[{"id":"从 inspect 取得的资产 ID","grade":{"multiply":[0.8,0.9,1.0]}}]}
```

```json
{"action":"export","suffix":"_场景匹配","outputDir":"配色输出"}
```

## 参数与输出一致性

网页保存每张资产的独立状态。手调只改变页面；没有后台持续上报。`export` 开始时拷贝所有待输出资产参数，再顺序调用已有满分辨率渲染器，单张结果作为 PNG 交给本地服务。

服务使用排他创建文件（`wx`）；同名自动编号，并以自己实际写入的路径回应智能体。网页不能伪造一组“已输出路径”让服务当作成功。输出只允许在当前项目的真实目录内；载入文件和输出目录均检查符号链接/目录联接是否越界。

源图按需存到项目私有缓存。缓存只用于读图和重新载入，不用成品替换它。会话停用后不自动清理，避免意外删除；项目换目录时关闭旧会话、建立新会话。

指令 60 秒未确认会取消等待、清除未交付队列，不自动重放。已在网页执行的调节可能保留，已保存文件也保留，`inspect` 可查询历史输出；先核对再决定是否重试。网页仍连接是智能体渲染的前提。

## 文件职责

- `web/index.html`：UI、原始图对象、参数校验与唯一的像素渲染实现；`window.assetColorMatch` 暴露窄接口。
- `web/bridge.js`：网页与插件的协议；只在服务端提供网页时注入。
- `server.js`：会话、鉴权、命令队列、项目范围文件读写。
- `index.js`：DSH 注册、每对话会话和工具参数 schema。
- `cordis.patch.yml` + `package.json`：原生 bundle 安装入口。
- `tests/session.test.mjs`：真实 HTTP、文件系统、取消与注册适配检查。
- `tests/legacy-web.cjs`：小型 DOM/Canvas 替身，数值与页面状态回归检查。
