# DSH 资产光影匹配

给 AI 视频的角色、服装和道具参考图统一色调：**智能体看图并填写数值，你在默认浏览器查看，可手调，也可直接让智能体输出。**

以 Grade 为主，按需加入 Keyer 和 ColorCorrect（CC）。保留单文件网页的轻量实现，运行时零第三方依赖，无需安装 Nuke。当前为 **0.1.0 预览版**。

## 安装

适配目标：Windows、支持 Cordis bundle 的 DeepSeek Harness Desktop；接口按本机 **DSH 0.2.2-rc.3** 的 `tools / commands / agents / workingDirectory` 实现。其他宿主版本需重新验收。

1. 从 [Releases](https://github.com/zxw219/dsh-asset-color-match/releases) 下载 `dsh-asset-color-match-0.1.0.tgz`，或把仓库源码保存到本机。
2. 在 DSH 的插件管理界面，以本地 `.tgz` 或源码目录的**绝对路径**安装 bundle，并启用 `dsh-asset-color-match`。不同 DSH 版本的入口名称可能不同；若版本不接受目录，使用 `.tgz`。
3. 按安装器提示重新加载；只有宿主明确要求时才完全退出再启动。插件自身不修改 DSH 安装包。
4. 进入你的电影项目对话，输入 `/asset-color-match`，或让智能体调用 `asset_color_match` 的 `open` 操作。

如果你的旧版 DSH 暴露 `plugin_manager` 工具，也可让它执行 `action: "install_bundle"`、`target: "本地包或目录绝对路径"`。此工具并非所有版本都有；不要把它当本插件提供的工具。

本仓库尚未发布到 npm。普通 `npm install dsh-asset-color-match` 不是本版本的安装方式。

## 日常使用

1. 打开网页，把场景图放左上，角色、服装等资产图放左下。智能体也可用 `load` 载入当前 DSH 项目中的图片路径。
2. 对智能体说：**“读一下参考图和这些资产图，帮我填好数值。以 Grade 为主，Keyer 和 CC 按需使用，先不导出。”**
3. 智能体调用 `inspect` 取得原图缓存路径，用 DSH 自带读图工具实际看图，再调用 `set` 填值。网页立即显示结果。
4. 你可以继续手调，也可以直接说：**“按网页当前数值输出全部。”** 智能体调用 `export`，网页按此刻参数逐张原尺寸渲染，插件保存并返回结果路径。

也可直接点击网页的“导出当前 PNG”或“批量导出全部”。插件模式默认保存至 **当前 DSH 项目 / 配色输出**；同名加 `_1`、`_2`，原图保留。智能体可指定项目内其他输出目录。

**手调没有持续同步给智能体。** 只有 `inspect` 或执行指令时按需读取；导出采用网页当时的参数，不用上一次智能体填写的旧值覆盖它。一次批量导出开始后，该批参数固定，过程中再手调留给下次导出。

每个 DSH 对话对应一个工作台。保持原页面开启；同一对话不要同时开多个工作台标签。网页刷新会丢失尚未保存的素材队列和参数，重要结果请先“导出参数”。参数包不包含原始图片，重新打开后还需载入原图。

## 三种调节的用途

| 控制 | 用途 | 建议 |
|---|---|---|
| Grade | 黑白位、RGB 增益、偏移和 Gamma，调整整体亮度与环境冷暖 | 主要使用 |
| Keyer | 按亮度、通道或饱和度生成 A/B/C/D 渐变选区 | 需要局部限制时启用 |
| CC | 对整体、暗部、中间调、亮部调整饱和度、对比度、Gamma、增益和偏移 | Grade 后做小幅修正 |

Keyer 默认不改变透明度，也不理解“皮肤”“衣服”等物体语义。它的遮罩可限制 Grade / CC，勾选透明度选项才参与输出 Alpha。CC 不会生成新的光向或投影。复制 Nuke Grade 仅适用于兼容的全局 Grade；启用局部遮罩、CC 或额外饱和度时，用 PNG 或完整参数包保留效果。

原型保留了自动统计匹配和场次预设。自动统计不等同于智能体看图；“人像保肤”模式也不是语义皮肤分割。示例数值针对原项目的特定图片，新场景需要重新判断。

## 来源、思路与 Nuke 的关系

它从《凌云渡》AI 电影项目中用户提供的 **“资产光影匹配工具.html”** 演变而来。用户希望处理供 AI 视频参考的角色与服装图；在经历 Nuke 脚本工作流不便后，选择保留本地网页，由智能体代填数值。

设计借用合成师的顺序：**先读场景光线与资产，再做全局 Grade，必要时用 Keyer 限制范围、CC 修正局部，最后比较并输出。** 智能体承担观察和参数建议，用户保留最后判断；计算由确定的像素算法执行。

这是独立的 DSH 插件，和 Foundry / Nuke 无官方关系，也不替代合成师对光向、接触阴影、空间、边缘和镜头连续性的判断。它迁移颜色与明暗倾向，不做真实重打光，也不保证 AI 视频模型严格沿用参考色。

更详细的制作经过、作者职责和数值验证范围见 [来源与设计](docs/PROVENANCE.md)；代码结构与接口见 [实现说明](docs/ARCHITECTURE.md)。

## 本地与隐私

- 网页和插件仅通过 `127.0.0.1` 随机端口通信，接口需要随机令牌，并拒绝跨站请求和其他 Host。
- 本插件没有云端服务、模型 API、API Key、图片外传或遥测。**DSH 智能体实际读图时是否送往模型服务，取决于 DSH 与所选模型的配置**，不属于“网页本地计算”的保证。
- 用户在网页选中的原图只在请求时复制到项目的 `.dsh-asset-color-match/<会话 ID>/`，供本地智能体读图。`load` 只能读取当前项目中的路径；项目外图片由用户在网页自行选择。
- 原图缓存与成品会保留；停用插件不自动删除。无需继续使用时，可在确认后手动清理缓存目录。
- 工作台链接包含临时控制令牌，不要公开分享。Git 和安装包不含用户图片、缓存、令牌或项目输出。

## 验证与限制

开发者在源码目录运行（Node.js 22+，无需 `npm install`）：

```powershell
npm run check
npm test
npm pack --dry-run
```

已通过 6 组服务/宿主适配测试和 91 项像素、参数及导出检查；另在真实浏览器中验证了本地连接、载图、Grade/Keyer/CC 填值、手调后导出、网页按钮保存。测试图为合成的 1×1 PNG，输出像素已由独立 PNG 解码器读取。

**未完成真实 DSH 插件安装、对话内工具调用及系统默认浏览器启动的端到端验收。** 本次浏览器验证使用开发测试入口；它证明网页和本地桥接流程，不代表宿主安装已通过。DSH 注册入口另有适配单元测试。

输入支持 PNG/JPEG/WebP/GIF，单张原文件不超过 64 MB；GIF 按浏览器解码的静态帧处理。输出为原尺寸 8-bit sRGB PNG，PNG 请求不超过 64 MB、尺寸上限 1 亿像素；实际可处理大小受浏览器内存限制。未做超大图压力测试。

只实现 sRGB ↔ Linear 的这条轻量管线，不支持 EXR、ACES/OCIO、HDR、多帧视频或完整 ICC 工作流。不能承诺任意 Nuke 项目、显示器或软件间“零色差”。导出要求网页保持连接；60 秒未确认即报超时，可能已有部分文件，**先检查结果再重试**。

## 更新

普通使用者：先导出参数包备份，再下载安装新 Release，通过 DSH 插件管理更新同名 bundle，重新打开工作台并载入原图、参数包。

维护者：见 [更新与发布](docs/UPDATING.md)。本插件没有静默更新器。电影项目里原来的 HTML 是历史副本；后续插件网页以仓库的 `web/index.html` 为准。

## 独立网页模式

双击 `web/index.html` 仍可离线手调、导入参数和下载 PNG；没有 DSH 控制和项目目录保存功能。`node server.js "项目目录"` 可启动本地开发工作台并打印地址，手动打开该地址；此命令不会自行连接 DSH 智能体。
